# 1. Sprint's backlog #

The sprint 1 backlog includes the development of structured cabling projects for several airport terminals.  
Each team member is assigned one terminal and is responsible for designing the structured cabling system for the floors encompassed in the project.

The tasks included in this sprint are:

* T.1.1 – Development of a structured cabling project for Terminal 2 encompassed floors, including the campus backbone.
* T.1.2 – Development of a structured cabling project for Terminal 3 encompassed floors.
* T.1.3 – Development of a structured cabling project for Terminal 5 encompassed floors.
* T.1.4 – Development of a structured cabling project for Terminal 4 encompassed floors.

Each task requires the development of a structured cabling deployment plan including:

* Calculation of the required number of network outlets for each room
* Deployment plan of network outlets (including outlets for wireless access points)
* Cross-connect deployment plan
* Cable pathways deployment plan
* Hardware inventory including cables, patch panels, outlets and telecommunications enclosures
