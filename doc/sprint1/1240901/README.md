RCOMP 2025-2026 Project 1 - Sprint 1 - Member 1240901 folder
===========================================
*Terminal 4*
================

### Brief description ###

<span style="color: #0ECFC5"> Level 0 (Arrivals): </span>

+ The ground level is equipped with an underfloor cable raceway. Access to this raceway is available at points marked on the building plan.

+ A vertical cable passageway is located in room 4 and connects all floors of the building. This passageway is linked to the external underground technical ditch. The vertical distance between this floor and the underground passageway connection is approximately 3 meters.

+ The ceiling height of this floor is 5 meters. However, a dropped ceiling is installed at a height of 4 meters, covering the entire floor. The space above the dropped ceiling can be used to install cable raceways, wireless access points, and other networking infrastructure.

+ Rooms 1, 2, 3, 5, 6, 7, 12, 13, 14, 15 and 16 must be provided with the standard number of network outlets according to the work area outlet density rule.

+ Rooms 4, 8, 9, 10 and 11 do not require network outlets.

+ Room 4 is suitable for housing network infrastructure equipment such as a cross-connect.

<span style="color: #45FF56"> Level 2 (Departures): </span>

+ Level 2 also contains an underfloor cable raceway along the external walls of the building, with access points marked on the building plan.

+ The ceiling height of this floor is 5 meters, with a dropped ceiling installed at a height of 4 meters covering the entire floor. This space above the ceiling can be used to install cable raceways and wireless access points.

+ A vertical cable passageway is also present in room 4, connecting this floor to the underground technical ditch. The vertical distance between this floor and the underground connection is approximately 15 meters.

+ Rooms 1, 2, 4, 5, 7, 9, 12, 13, 14, 15, 16, 17, 18, 19, 20 and 21 must be provided with the standard number of network outlets.

+ Rooms 3, 6, 8, 10 and 11 do not require network outlets.

+ Room 3 is suitable for housing network infrastructure hardware such as a cross-connect.

+ Along the external wall on the right side of the plan and along the external wall at the bottom side of the plan, one network outlet must be installed every 5 meters.
