## *Terminal 3*

### Brief description: ###

<span style="color: #0ECFC5"> Level 1 (Departures): </span>
 
+ Level 1 of Terminal 3 contains an underfloor cable raceway that allows the distribution of network cabling throughout the floor. Access points to the raceway are indicated on the building plan.

+ There are four vertical cable passageways that connect all floors of the building. These passageways are connected to the underground technical passageway of the airport infrastructure. The vertical distance between this floor and the underground technical passageway is approximately 10 meters.

+ The total ceiling height on this floor is 5 meters, with a dropped ceiling installed at 4 meters, covering the entire floor. The space above the dropped ceiling can be used to install cable raceways, wireless access points, and other network infrastructure.

+ Rooms 2, 4, 5, 7, 8, 9, 10, 12, 13 and 14 must be provided with the standard number of network outlets according to the work area outlet density rule.

+ Rooms 1, 3, 6, 11 and 15 do not require network outlets.

+ Rooms 1, 11 and 15 are suitable for housing network infrastructure equipment, such as cross-connects or racks.

+ Along the external wall on the left side of the building and along the external wall on the upper side of the plan, one ISO 8877 network outlet must be installed every 5 meters.

<span style="color: #45FF56"> Level 2 (Arrivals): </span>

+ Level 2 also contains an underfloor cable raceway for the distribution of network cabling across the floor, with access points indicated on the building plan.

+ This floor is also connected through four vertical cable passageways, which link the floor to the underground technical passageway of the airport.

+ The vertical distance between this floor and the underground connection is approximately 16 meters.

+ The ceiling height is 5 meters, and a dropped ceiling is installed at 4 meters, covering the entire floor. The space above the dropped ceiling can be used to install cable raceways, wireless access points, and networking infrastructure.

+ Rooms 2, 3, 4, 7, 10, 11, 12, 14, 15, 16, 17, 18 and 19 must be provided with the standard number of network outlets according to the work area outlet density rule.

+ Rooms 1, 5, 6, 8, 9, 13 and 20 do not require network outlets.

+ Rooms 1, 13 and 20 are suitable for housing network infrastructure equipment, such as cross-connects or racks.
